O trabalho

Fui estagiário de QA no BRB Card, o cartão do Banco de Brasília, de novembro de 2024 a abril de 2026. Em produto financeiro, um bug mexe com o dinheiro de cliente de verdade.

Fiz teste manual, funcional, de regressão e exploratório, modelei cenário, cacei bug e ajudei a automatizar o que dava. Nesse período tirei as duas certificações ISTQB.

↳ Automação E2E

Cypress &
fluxos críticos

Automatizei fluxos E2E com Cypress, organizando os seletores em Page Objects e os passos repetidos (como o login) em comandos customizados.

O código abaixo é um exemplo do estilo de teste que eu escrevia, não é código do BRB, que é confidencial.

exemplo · pagamento.cy.js
// Exemplo: pagamento de fatura
describe('Pagamento de Fatura', () => {
  beforeEach(() => {
    cy.loginBRB() // custom command
    cy.visit('/fatura')
  })

  it('deve exibir fatura do mês atual', () => {
    cy.get('[data-cy=fatura-valor]')
      .should('be.visible')
      .invoke('text')
      .should('match', /R\$\s[\d.,]+/)
  })

  it('deve processar pagamento via débito', () => {
    cy.get('[data-cy=btn-pagar]').click()
    cy.get('[data-cy=metodo-debito]').click()
    cy.get('[data-cy=confirmar]').click()
    cy.get('[data-cy=toast-sucesso]')
      .should('contain', 'Pagamento realizado')
  })
})

↳ BDD & Gherkin

Especificações
executáveis

Escrevi cenários BDD em Gherkin pra deixar a regra de negócio escrita de um jeito que produto, dev e QA liam igual. O exemplo abaixo também é ilustrativo.

exemplo · features/limite.feature
Funcionalidade: Consulta de Limite do Cartão

  Contexto:
    Dado que o cliente está autenticado no app

  Cenário: Cliente consulta limite disponível
    Quando o cliente acessa a tela de limite
    Então deve ver o limite total e o limite disponível
      E os valores devem estar formatados em reais

  Cenário: Sistema bloqueia operação acima do limite
    Dado que o cliente possui limite disponível de R$100
    Quando tenta realizar uma compra de R$150
    Então a transação deve ser negada
      E deve exibir mensagem "Limite insuficiente"
